# Informática do Zero

Página de vendas do curso Informática do Zero.

- `index.html`: a página (topo com o teclado que desmonta ao rolar, módulos, atalhos, perguntas e formulário de inscrição).
- `img/palco.jpg`: fundo do topo.

As inscrições do formulário são gravadas no Supabase, na tabela `inscricoes_informatica`.
